# تحسينات البحث والواجهة والرجوع — راتب 3.1.4

تتضمن هذه النسخة طلبات المستخدم الأخيرة، مع الحفاظ على بنية التطبيق وصيغ البيانات والمحاسبة والأيقونة المعتمدة.

## ما تغيّر

- يمكن حذف النص في خانات البحث بالمحو الخلفي أو Delete، من الوسط أو النهاية، دون تحديد الكل. لا تعيد الخانة ملء اسم الحساب أثناء الكتابة أو الحذف. يُعتمد الحساب بالنقر على النتيجة أو Enter.
- يظهر «الإصدار 3.1.4» تحت أزرار القائمة والوضع الليلي والمعاينة في الواجهة الرئيسية.
- أُخفيت عبارات الحفظ والعمل دون الإنترنت الدائمة. تظهر الجاهزية في تنبيه قصير عند تجهيز نسخة جديدة، ثم تختفي. يبقى طلب تطبيق التحديث ظاهرًا حتى اتخاذ القرار، ويظهر نجاح التحديث بصورة مؤقتة.
- يعود الرجوع إلى الشاشة السابقة التي فُتحت منها الصفحة، مع استعادة عرض التقرير أو الحساب ومرشّحاته، وبحث السجل، وحقول السند. يعود من نموذج السند إلى اختيار نوعه إذا دخل منه، ومن تعديل القيد المتعدد إلى السجل إذا دخل منه.
- بعد الوصول إلى الرئيسية، يعرض الرجوع تأكيد الخروج بخياري «موافق» و«البقاء في التطبيق». التركيز الافتراضي على البقاء؛ Enter الافتراضي وEscape يبقيان التطبيق مفتوحًا. زر الخروج في القائمة يعرض التأكيد نفسه.
- عند الموافقة تُحفظ البيانات والمسودة أولًا ثم تنتهي الجلسة. الضغط المتكرر لا يكرر الخروج؛ تعذّر الحفظ يبقي التطبيق مفتوحًا ويتيح إعادة المحاولة.

هذا السلوك يحل محل الخروج المباشر في النسخة 3.1.3، وفق الطلب الأخير.

## الرفع إلى GitHub

إذا كانت ملفات النسخة 3.1.2 أو 3.1.3 قد رُفعت بالفعل، فك ضغط ratib-interface-fix-3.1.4.zip واستبدل هذين الملفين في جذر المستودع فقط:

1. index.html
2. sw.js

لا يلزم إعادة رفع vendor أو Icons أو manifest.json. ملف README_AR.md شرح اختياري. تحتوي ratib-3.1.4.zip النسخة الكاملة إذا احتجتها.

بعد اكتمال نشر GitHub Pages افتح راتب مع الإنترنت، واضغط «حفظ المسودة والتحديث» عند ظهور التنبيه. يظهر رقم 3.1.4 في الرئيسية بعد تطبيق التحديث. احتفظ بعنوان التطبيق الحالي لاستمرار الوصول إلى بياناته. لم يُرفع التحديث إلى GitHub خلال هذه الجلسة.

## التحقق وحدوده

نجح 49 اختبارًا آليًا: 41 للتطبيق والمحاسبة والتخزين والبحث والرجوع والخروج، و8 للتحديث والعمل دون الإنترنت. اختُبرت الكتابة والحذف عند المؤشر، واستعادة الشاشة والحقول والمرشّحات، وخيار البقاء الافتراضي، وحفظ البيانات قبل التحديث والخروج.

تعذّر فتح المعاينة المحلية بأداة المتصفح المتاحة؛ لم تُراجع الواجهة بصريًا على الهاتف في هذه الجلسة. يلزم تجربة زر الرجوع وإظهار لوحة المفاتيح على جهاز المستخدم. داخل المتصفح قد يمنع المتصفح إغلاق التبويب نفسه؛ في هذه الحالة تنتهي جلسة راتب وتظهر شاشة الخروج. أُغلق التطبيق عبر واجهته الأصلية في الاختبارات بالمحاكاة، ولم يُختبر إغلاق نافذة هاتف مثبتة فعليًا.
