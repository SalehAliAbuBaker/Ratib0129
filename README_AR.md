# راتب — الإصدار 3.5.0

تحديث متكامل للاستيراد وميزان المراجعة وأدوات الإدخال، مع المحافظة على السند الموحد للقبض والصرف والقيد البسيط والمركب.

## الاستيراد

ضمن إدارة الحسابات قائمة مختصرة للاستيراد من Excel أو نظام خارجي وتنزيل نموذج XLSX فارغ. تقرأ الأداة XLSX وXLS وCSV وTSV بالإضافة إلى JSON المهيأ لراتب. تقترح مطابقة العناوين والعينات وتسمح بتغييرها أو تجاهل الأعمدة وحفظ المطابقة باسم المصدر. لا تعتمد ترتيب الأعمدة، ولا تُرحّل بمجرد اختيار الملف.

النموذج يحتوي سبعة أعمدة للحساب والأب والتصنيف والعملة والأرصدة المدينة والدائنة، وتعليمات وقوائم تحقق. يبقى الحساب واحدًا مع أرصدة منفصلة لكل عملة. الأكواد النصية والأصفار البادئة محفوظة. تعارض الهيكل أو الاسم أو الحساب الأب أو تكرار الحساب والعملة أو رصيد مباشر على حساب تجميعي يحتاج مراجعة. يحتفظ الاستيراد بالهيكل الأصلي في سجل الدفعة، مع عرض الأقسام وفق مستويات دليل راتب الحالية.

المسار: الملف، مراجعة الأعمدة، مطابقة الحسابات ومعاينة الأرصدة والقيد الافتتاحي، عرض الأخطاء، موافقة المستخدم، نسخة أمان، حفظ ثم تقرير تحقق. الحسابات الجديدة لا تُنشأ أثناء المعاينة. أرصدة العملات الأجنبية تتطلب تقييمًا مسجلًا في الملف أو سعرًا يدخله المستخدم ويعتمده؛ لا تُستنتج أسعار جديدة من الأرصدة. تبقى طبيعة المدين والدائن والعملة الأصلية مستقلة عن التقييم. الاستبدال اختياري وصريح، والتراجع يستعيد البيانات السابقة ما لم توجد حركات مالية أحدث ينبغي حفظها أولًا. لا يقرأ التطبيق PDF مباشرة.

## ميزان المراجعة

يعرض الافتتاحي وحركة الفترة والختامي، بفترة من/إلى، وبند ميزانية افتراضي «عام»، وعملة عرض افتراضية YER، ومراكز تكلفة ومشاريع من البيانات المسجلة فعلًا. تظهر خيارات هذه المرشحات عند وجود بيانات لها، دون إنشاء مراكز أو مشاريع تجريبية.

طرق العرض: العملات الأصلية، عملة محددة، المعادل، الأصلية والمعادل. يوجد اختيار مستوى الحسابات والعرض الختامي المختصر. يظهر كل حساب مرة واحدة وتتفرع عملاته تحته، والإجماليات والفرق مستقلة لكل عملة. المعادل يعتمد التقييم المسجل أو سعر المستند؛ عند نقص السعر يعرض التقرير «غير متاح/غير مكتمل» دون موازنة مصطنعة. تنبه المرشحات الجزئية إلى أن التقرير قد يستبعد بعض أطراف القيود.

المعاينة والطباعة وPDF وXLSX تستخدم المرشحات والنتائج نفسها. PDF أفقي A4 بعناوين متكررة وأرقام لا تنقسم داخل الخلايا. تصدير Excel ملف XLSX فعلي يحتوي المرشحات والأرصدة والإجماليات والتنبيهات.

## أدوات الإدخال والتحديث

حاسبة مشتركة للمبالغ والأسعار والأرصدة بعمليات عشرية دقيقة. تعلن دقة الحقل والنتيجة المقربة قبل استخدامها؛ استخدامها يعيد الحساب ولا يحفظ سندًا، وإغلاقها يحافظ على القيمة الأصلية. البيان العام يسبق المستفيد في الإدخال والطباعة والتصدير. التفقيط يتضمن الكسور ووحدات العملة، ويحافظ على الكسور الإضافية بدل إسقاطها.

حقول الأسعار مالية وتستخدم لوحة أرقام عشرية؛ حقول كلمات المرور الحقيقية تبقى في نماذج مستقلة. سلوك اقتراحات كلمات المرور النهائي يتبع المتصفح. تظهر أهم تغييرات كل إصدار قبل تطبيق التحديث وبعده؛ تطبيقه يحفظ المسودة والبيانات قبل تفعيل الإصدار الجديد.

## البيانات والتحقق

بنية قاعدة البيانات والتشفير ومنطق تسجيل السندات الحالية محفوظة. بيانات الاستيراد محلية ولا تدخل في كود التطبيق أو ملف النموذج أو المستودع العام. لا تتضمن هذه النسخة حسابات أو أرصدة خاصة بمستخدم أو بيانات اختبار.

نجح 179 اختبارًا آليًا للحفظ والاستعادة والتشفير والسندات والمصارفة والرجوع والاستيراد وميزان المراجعة والحاسبة والتحديث. شملت الاختبارات استيراد XLSX فعليًا مع نسخ الأمان والحفظ وإعادة الفتح والتراجع، والعملات المختلطة وأسعار الاتجاه العكسي. شمل فحص المتصفح 24 حالة بعروض 320 و360 و768 و1280 بكسل للسند والقيود والحاسبة والتقرير والاستيراد، وفُحص PDF بصريًا. لا يغني ذلك عن تجربة الهاتف الفعلي.
