## البناء والفحص

يتطلب Node 24 أو أحدث وJDK 17 وAndroid SDK 36 وGradle 8.13. ينفذ البناء `tools/bundle-web.cjs` لضم ملفات الويب مع خطافات Android السابقة دون تغيير الحسابات أو التخزين. تحتوي source-manifest.json المولدة على إصدار الحزمة والبناء وبصمات الملفات.

```sh
npm ci --ignore-scripts
npm run assets:brand
npm test
node android/tools/bundle-web.cjs
node android/tests/startup215.cjs
node android/tests/native-bridge.cjs
cd android
./gradlew assembleRelease
```

على Windows تستخدم أداة `android/tools/build-apk.ps1` مسارات SDK وJDK وGradle ومفتاح التوقيع وملف كلمة مروره كمدخلات. تُطبّع مسارات ZIP قبل التوقيع، ثم يُفحص التوقيع وسلامة الحزمة. لا تدخل المفاتيح وكلمات المرور والاعتماديات ومخرجات البناء إلى المستودع.

الأيقونة التكيفية تتكون من خلفية خضراء وطبقة أمامية تحافظ على الشعار الكامل، مع ملفات عادية ودائرية لجميع الكثافات. يوجد مورد بدء للإصدارات السابقة وتهيئة شاشة بدء النظام في API 31 فأحدث.

التحديث الآمن للجهاز الموجود يستخدم `adb install -r` بعد تطابق الشهادة والحزمة وارتفاع versionCode. لا يستخدم إزالة التطبيق أو مسح بياناته. نجاح التثبيت لا يثبت وحده تطابق كل سجل مالي؛ يجب تمييز نتيجة الاختبار المرئي عن مراجعة البيانات الكاملة.
