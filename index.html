غير مفعّل
كيف أحصل على المعرّف؟ (مرة واحدة)
  1. افتح console.cloud.google.com وأنشئ مشروعاً، ثم فعّل "Google Drive API".
  2. من "OAuth consent screen" اختر External وأضف بريدك ضمن Test users.
  3. من Credentials أنشئ "OAuth client ID" نوع Web application.
  4. ضمن Authorized JavaScript origins ضع رابط موقعك بالضبط، مثل: https://اسمك.github.io
  5. انسخ الـ Client ID والصقه هنا. لن يعمل الربط إذا فُتح التطبيق كملف محلي أو من واتساب، بل يلزم رابط https.
